# Historical LaTeX baseline

This source predates the ITSAC conference manuscript. It is retained to identify the baseline used by the subsequent analysis and figure files.

Compile `main.tex` with pdfLaTeX, BibTeX and two further pdfLaTeX passes. Compile `supplement.tex` twice separately. The directory includes the required class and style files, references, figure PDFs and editable PowerPoint artwork.

Figure 1 is a schematic overview; its illustrations are not measured network data. See the supplementary source for artwork provenance and the [analysis guide](../../../REPRODUCTION_README.md) for data and reproduction limits.
