# First manuscript

The complete English manuscript is `first_manuscript.md`. It uses a venue-neutral transportation/ITS structure: abstract, introduction, related work, problem formulation, framework, experimental design, results, discussion, conclusion, references, and three appendices.

## Contents

- `first_manuscript.md`: reading and conversion entry point.
- `manuscript.template.md`: editable prose source; marked table blocks are populated from the final data package.
- `build_manuscript.py`: builds the manuscript, three new scientific figures, and numerical tables; copies three existing project figures.
- `figures/`: six figures with PNG previews and available PDF/SVG versions.
- `references.bib`: 14 bibliographic entries, in manuscript citation order.
- `validation.json`: artifact checks, source hash, and manuscript hash.

From the project root, regenerate with:

```powershell
python manuscript/build_manuscript.py
```

The script uses the existing final results and does not call an LLM or run simulation experiments. Edit prose in the template before rebuilding. Generated tables use `outputs/paper_final/results.json`; geographical Table 2 uses `outputs/cross_site/site_morphology_comparison.csv`. The E1 illustrative execution sequence is supported by `outputs/experiment1_final/E1_H_H_high_case_study.csv`. Protocol definitions come from the final scenario manifests and frozen source snapshot.

## Conversion conventions

The manuscript intentionally has no publisher-specific class, layout, author block, or fabricated funding/affiliation declarations. Author and submission metadata can be supplied when a venue is chosen.

- Eight numbered main sections and numbered subsections are explicit in the headings.
- Six figures, fourteen tables, eleven display equations, and fourteen references retain explicit numbering.
- HTML anchors such as `sec-5-4`, `fig-3`, `tab-5`, and `eq-8` identify cross-reference targets. Convert these to LaTeX `\label{...}` and the matching links to `\ref{...}`.
- Equations use standard LaTeX math and `\tag{n}`. In numbered LaTeX equation environments, replace the tags with labels.
- Citations are linked numeric labels `[[n]](source-url)`. Replace them with `\cite{key}` using the ordered key map below.
- Image links use absolute local paths so the desktop Markdown preview displays them. During conversion or relocation, resolve each image by its basename in `figures/`. Prefer PDF or SVG for final typesetting where available; Figure 2 has its original PDF, and Figures 5–6 have SVG source assets.
- Captions follow their figures and precede their tables. Preserve their wording when moving them into floating environments.
- Three appendices use A–C headings; table numbers continue the main sequence to avoid ambiguous duplicate labels.
