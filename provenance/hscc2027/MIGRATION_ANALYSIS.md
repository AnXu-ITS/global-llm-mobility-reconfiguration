# 转向分析与本次整理边界

日期：2026-09-18。依据：根目录《HSCC_ICCPS_2027_研究方向转向计划书.md》及本地源码静态检查。

## 研究判断

转向的实质是把研究对象从“地空协调/监督策略谁更好”改成“慢提案器工作期间，执行系统如何保留仍然可行的服务恢复机会”。LLM 是可替换的慢提案器；核心贡献应来自异步执行、时间预算、资源承诺和物理交接的共同约束。

这一转向有明确的工程切入点，但贡献尚未由实验确立。最关键的证据是：在相同物理语义、相同信息权限下，相对简单最晚启动规则 X_LST 和直接快速 B2，联合机制是否仍有可解释的收益或独立的协议性质。不能通过未修复的旧队列、错误的物理动作或人为延迟 B2 制造优势。

第一优先级应是修正版基线桥接和最小异步诊断，其次是唯一载荷、逐任务地面运输与交接，再开展有限机制比较。计划中的 3,060 次确定性仿真和原生模型实验只是候选预算，本次整理没有启动这些工作。
