# Historical ground–air simulation platform

This directory retains the earlier implementation, configurations, analysis scripts and regression records. The ITSAC paper's current documentation, final manuscript and numerical verification are maintained on the [paper branch](https://github.com/AnXu-ITS/global-llm-mobility-reconfiguration/tree/itsac-restored-20261016).

See the [supplement](https://github.com/AnXu-ITS/global-llm-mobility-reconfiguration/tree/itsac-restored-20261016/itsac/supplement) for the available data and model scope, and [the local analysis guide](manuscript/REPRODUCTION_README.md) for historical postprocessing requirements.

The later runtime project reuses selected platform components through its versioned vendor directory. Its development results are separate from the ITSAC experiments.
