## 术语与主体

| 术语 | 本轮用法 |
|---|---|
| Manager | 服务层面的监督架构，沿用原稿简称 |
| supervisor | 选择服务干预 |
| candidate generator | 产生并说明可执行候选及其后果 |
| executor | 检查、排队及实施命令 |
| local contingency | 独立于监督命令队列执行 |
| remaining service margin | 服务链尚可使用的时间，不等同于飞行速度优势 |
