# 人工改图

Figure 1 快捷方式仍打开当前 PowerPoint。Figures 2–6 的新快捷方式打开 SVG/PDF 文件夹，文字、数据格和图形路径均可编辑。

源文件与论文图号的对应见 overleaf/editable_figures/EDITING_GUIDE.md，设计规则见 overleaf/FIGURE_STYLE_GUIDE.md。Figure 5 的原差值图已移至 Figure S3。

修改 Python 生成脚本或保留的 PPT 后，可双击“改图后更新论文.cmd”。程序先备份，再生成矢量图并编译主文和补充材料。直接改 SVG 时，也要将改动写回 Python 源，否则重新生成会覆盖 SVG 中的手工调整。只改论文文字时运行 overleaf/scripts/build.ps1，不加 -ExportFigures。

旧七页 PPT 已归档，其中第 4、7 页仍为 S1、S2 的可编辑源。当前 Figures 2–6 不再从该 PPT 导出。
